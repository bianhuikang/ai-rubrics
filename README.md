# AI Rubrics Judge 使用说明

这是一个用于网页产物验收的 rubrics 检查工具。系统支持创建任务、维护 rubrics、逐个页面手工检查，并把完成后的评分结果同步到飞书在线表格。

## 启动

1. 安装依赖：

```bash
npm install
```

2. 启动服务：

```bash
npm run dev
```

3. 打开页面：

```text
http://localhost:3000
```

局域网内其他人访问时，使用部署机器的 IP 和端口。

## 创建任务

在主界面填写：

- 任务 ID
- Prompt
- URL 列表
- rubrics

rubrics 可以手工填写，也可以留空自动生成。粘贴 rubrics 时，开头的 `1.`、`2.` 这类序号会自动清理。

## 手工检查

任务创建后，在主界面打开任务详情，点击每个 URL 后面的“手动检查”。

检查页面会逐条展示 rubrics：

- 符合：点击“符合”
- 不符合：点击“不符合”，并填写原因

每一次操作都会保存到后端，多人使用时不会只停留在前端本地。

## 修改 Rubrics

在主界面可以修改或删除 rubrics。

如果任务发生过 rubrics 修改，任务列表会用棕色背景提醒。这个标记用于提醒用户：甲方飞书表格里的 rubrics 也可能需要同步更新。

## 复制结果

任务完成后，主界面可以复制：

- 评分结果
- 不符合原因汇总
- rubrics

复制 rubrics 时，也会再次清理开头序号，避免旧数据残留。

## 飞书同步插件

项目包含一个 Chrome 插件目录：

```text
chrome-extension
```

安装方式：

1. 打开 Chrome 扩展程序页面。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择项目里的 `chrome-extension` 目录。

使用方式：

1. 打开飞书在线表格里的记录卡片，打开表单模式。
2. 插件会显示当前识别到的任务 ID。
3. 点击“同步当前记录”。
4. 如果任务已完成，插件会把评分和备注写入飞书字段。
5. 如果任务没完成，插件会提示“任务未完成”，不会写入飞书。

如果 rubrics 被修改过，请先清空rubrics内容，插件会尝试同步 rubrics 字段；

## 删除任务

任务列表支持删除任务。删除后，该任务的结果、日志和手工检查草稿会一起删除。
